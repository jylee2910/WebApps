# 끄적끄적 스케치북

브라우저에서 바로 쓰는 그림판입니다. 설치나 빌드 없이 `index.html`만 열면 됩니다.

## 할 수 있는 것

| 기능 | 설명 |
| --- | --- |
| 펜 10종 + 지우개 | 펜 · 붓 · 연필 · 마커 · 캘리 · 크레용 · 에어브러시 · 네온 · 무지개 · 스케치 |
| 필압 | **자동**(펜은 실제 필압, 마우스·손가락은 속도로) · **속도** · **펜 필압** · **고정**, 필압 곡선 조절, 실시간 필압 막대 |
| 손떨림 보정 | 0~95 단계, 끝부분은 실제 펜 위치까지 따라붙음 |
| 도형 다듬기 | 획 끝에서 0.5초 멈추면 원 · 타원 · 직선(45° 스냅) · 호 · 꺾은선 · 삼각형 · 사각형 · 다각형으로 정리 |
| 대칭 | 좌우 · 상하 · 4방향 · 회전 6 · 만화경 12 |
| 이미지 덧그리기 | 버튼 / 끌어놓기 / 붙여넣기(Ctrl+V)로 불러오기, 비침 조절, 캔버스를 이미지 크기로 |
| **이미지에 녹이기** | 그린 선을 사진의 빛 · 색감 · 질감 · 입자에 맞춰 합성 (슬라이더로 바로 미리보기, 누르고 원본 비교) |
| **닮은 이미지 찾기** | 낙서를 AI가 알아보고 위키미디어 공용에서 찾은 뒤, 내 그림과 닮은 순서로 정렬 |
| 기타 | 채우기, 스포이드(Alt+클릭), 종이 6종(줄노트·모눈·도트·크라프트·검정), 겹치기 모드(곱하기 등), 되돌리기, 확대/이동, PNG 저장 |

### 단축키

`1`~`0` 펜 고르기 · `B` 펜 · `E` 지우개 · `G` 채우기 · `I` 스포이드 · `H` 손 · `[` `]` 굵기
`Space`+끌기 이동 · `Ctrl+휠` / 두 손가락 확대 · `Ctrl+Z` / `Ctrl+Shift+Z` · `Ctrl+S` 저장 · `Ctrl+O` 불러오기

태블릿 펜을 한 번 쓰면 그 뒤로 손가락 터치는 그리기 대신 화면 이동으로 바뀝니다(손바닥 오인 방지). 펜 뒤꼭지(지우개 버튼)는 자동으로 지우개가 됩니다.

## 실행

```bash
# 그냥 열어도 되지만, AI 모델 캐시를 쓰려면 로컬 서버를 권장
npx http-server sketch -p 8080   # 또는: python3 -m http.server -d sketch 8080
```

GitHub Pages로 올리면 `https://<사용자>.github.io/WebApps/sketch/` 에서 바로 쓸 수 있습니다.

## 두 가지 아이디어에 대해

### ① 대충 그린 그림과 닮은 이미지 찾기 — 구현됨

- 브라우저 안에서 [transformers.js](https://huggingface.co/docs/transformers.js)로 **CLIP** 모델(`Xenova/clip-vit-base-patch32`)을 돌립니다. 서버나 API 키가 필요 없고, 그림이 밖으로 나가지 않습니다.
- 순서: 그린 부분만 잘라 정사각형으로 → CLIP이 단어장 180개 중 무엇인지 추측(상위 6개를 칩으로 표시) → [Wikimedia Commons API](https://commons.wikimedia.org/w/api.php)로 검색 → 찾은 이미지마다 CLIP 임베딩을 구해 **내 그림과의 유사도로 재정렬**.
- 결과를 누르면 배경으로 불러와 그 위에 덧그릴 수 있습니다(따라 그리기 연습에 좋음).
- 한계: 처음 한 번 모델 약 150MB를 받습니다(이후 브라우저 캐시). CLIP은 "무엇을 그렸는지"는 잘 맞히지만 "구도가 똑같은 사진"을 찾는 데는 약합니다. 더 정밀하게 하려면 스케치 전용 검색 모델(예: 스케치-사진 쌍으로 학습한 SBIR 모델)과 미리 임베딩해 둔 이미지 색인이 담긴 서버가 필요합니다.

### ② 불러온 이미지에 대충 그린 것을 자연스럽게 합치기 — 구현됨(비생성형), 생성형은 확장 과제

지금 들어 있는 **이미지에 녹이기**는 생성형 AI 없이 Lab 색공간에서 계산합니다.

1. **빛 따르기**: 주변 사진의 밝기에 맞춰 선을 어둡게/밝게
2. **색감 맞추기**: 사진의 채도 수준과 주변 색 기운을 빌려옴
3. **질감 비치기**: 사진의 밝기 결을 선 위로 겹침
4. **가장자리**: 사진의 초점감에 맞춰 경계를 부드럽게
5. **입자감**: 사진의 노이즈 크기를 추정해 같은 만큼 입자를 넣음

빠르고(슬라이더로 바로 미리보기) 결과가 예측 가능하지만, "낙서를 사진 속 진짜 물체로 바꿔 그려주는" 수준은 아닙니다. 그건 **생성형 모델**(Stable Diffusion + ControlNet Scribble / 인페인팅 같은 방식)이 필요하고, GPU 서버나 외부 API 키가 있어야 합니다. 붙인다면 흐름은 이렇습니다: 사진 + 낙서 마스크 + "무엇을 그렸는지"(①의 추측 결과를 그대로 프롬프트로 사용) → 인페인팅 API → 결과를 새 레이어로 받아 지금의 녹이기 슬라이더로 마무리.

## 파일 구성

```
sketch/
├─ index.html
├─ css/style.css
└─ js/
   ├─ util.js       색 변환(sRGB↔Lab), 난수, 캔버스 도우미
   ├─ brushes.js    펜 10종과 획 엔진(곡선 보간, 필압→굵기, 대칭, 다시 그리기)
   ├─ shapes.js     도형 인식(직선·호·원·타원·다각형)
   ├─ harmonize.js  이미지에 녹이기
   ├─ labels.js     낙서 인식 단어장(영어|한국어)
   ├─ search.js     CLIP 인식 + 위키미디어 검색 + 유사도 정렬
   └─ app.js        캔버스, 입력·필압, 도구, 되돌리기, 이미지, 저장
```
